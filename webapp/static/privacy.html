Who operates this service?

Data Quality Detective is operated by Shahed. For privacy and support requests, email shahed2338@gmail.com.

What information is processed?

The app receives the file you choose, its filename, worksheet names and spreadsheet contents to perform the analysis you request. Reports and exports may reproduce file contents, including hidden worksheets in separate audit reports. The browser keeps the selected file and results in the current page. The application does not send your data to an AI provider, advertising service or analytics service.

Where does processing happen?

On the public website, files up to 4 MiB are sent to Vercel servers for analysis. Processing is server-side, not solely in your browser. Vercel provides hosting, network security and operational logging; its infrastructure may process technical connection information such as IP addresses. See Vercel's privacy policy. Exact provider log retention and processing location have not been independently verified. The separately installed local app processes files on the computer running it and supports files up to 1 GiB. The public website does not provide the 1 GiB workflow.

Retention and deletion

The ordinary analysis API does not intentionally store uploads in an application database. Large-file processing writes CSV, XLSX or XLSM chunks to temporary disk and deletes the source when inspection or cleaning preview finishes, fails or cancels. Cleaning can create a temporary SQLite index and a separate prepared output. The index is deleted after processing; the output waits for your confirmation, download, discard or expiry. Only one pending large job or prepared output is allowed. Downloaded output is removed from server storage after the transfer finishes or fails. Processing and download transfers have 15-minute deadlines. Cancel requests stop processing and remove temporary data when the reader stops; a transfer already downloading must finish or disconnect first. A background sweep runs every 30 seconds while the server runs and removes inactive jobs older than one hour; active chunks renew that timer. Unstarted download requests expire after a minute. At most 20 completed overview reports are retained in server memory in addition to the current job. Normal shutdown removes temporary files; a crash or forced termination can leave files for operating-system cleanup. This is not secure disk erasure. Public hosting retention is unverified. Downloaded reports remain on your device until you delete them. Refreshing closes browser analysis state but does not cancel an active server job. Do not upload sensitive information to an unreviewed public deployment.

Cookies and browser storage

This app sets no application cookies and uses no localStorage, sessionStorage, advertising identifiers or analytics. The light/dark choice exists only in memory until reload. No optional tracking is enabled, so there is no optional cookie category to accept. Vercel security features may use security cookies or browser verification independently of this app; no optional advertising or analytics category is enabled by the application. If nonessential storage or tracking is introduced, it must remain disabled until the required consent mechanism and disclosures are in place.

Security and workbook preservation

Uploads are treated as untrusted data. The website does not execute VBA, macros, formulas or external workbook links. The original file remains unchanged. Preserved Excel cleaning copies edit only reviewed literal cells; formula cells and row deletion are blocked. Changing cell inputs can affect calculations, validation rules or macro behavior. Verify any changed copy in a trusted Excel environment before use, and never enable macros from an untrusted source.
