    Run locally — keep your files on your computer

    Process up to 1 GB locally

    More control over your data privacy. In local mode, spreadsheet uploads go only to the server running on your own computer. This app does not send those local uploads to Vercel, an AI provider or an analytics service. Temporary processing files and downloaded reports can remain on your device; local processing is not a malware scan or secure-erasure guarantee.

    For files larger than the 4 MB website limit, run this free app on your Windows PC or Mac. Local large-file mode accepts up to 1 GiB (1,073,741,824 bytes). Files are processed on your computer; no Vercel account, payment or Microsoft Excel installation is needed.

    Open my local app — start it using the steps below first. If port 8000 is busy, use the address printed in your terminal.

    Before you start

    1. Install Python 3.12 or 3.13 from python.org. On Windows, enable the installer option to add Python to PATH if offered. Reopen your terminal after installation.
    2. Download the app ZIP, extract it, and open the extracted folder containing pyproject.toml. Internet is needed for installation; local file processing does not need a hosting service.
    3. Keep at least 5 GiB of temporary disk space free for cleaning a 1 GiB file. Only one large job runs at a time. Very complex, encrypted or unsupported files may be rejected below the size limit.
    Windows — PowerShell setup

    Open the extracted folder in File Explorer, right-click inside it and choose Open in Terminal. Select PowerShell. Run each line:

    python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[web]"
.\.venv\Scripts\python.exe -m webapp.launch_local

    If python is not found, try py -3.12 for the first two commands after installing Python 3.12. No environment activation or PowerShell execution-policy changes are needed. Next time, run only the last command from this folder, or double-click START_DATA_QUALITY_DETECTIVE.cmd.

    Mac — Terminal setup

    Open Terminal, type cd (with a space), drag the extracted app folder into the terminal, and press Return. Run each line:

    python3 --version
python3 -m venv .venv
./.venv/bin/python -m pip install -e ".[web]"
./.venv/bin/python -m webapp.launch_local

    Use Python 3.12 or 3.13 from python.org, not the system Python. If needed, use python3.12 instead of python3 for the first two commands. Next time, open this same folder in Terminal and run only the last command. The app supports Intel and Apple Silicon Macs through compatible Python packages; native Mac installation has not yet been tested on Mac hardware.

    Check that local mode is working

    1. The command opens a browser at http://127.0.0.1:8000 (or another available port). Check that the badge says FREE LOCAL WORKSPACE, rather than FREE WEB TOOL.
    2. At the bottom, expand Large files · up to 1 GiB · on this computer. Choose a CSV, XLSX or XLSM file and select Inspect large file. Start with a small test file to confirm setup.
    3. Choose a worksheet for Excel, download the overview, or expand Prepare a cleaned large-file copy. Preview changes, confirm and download a separate copy. Your original stays unchanged. Large mode provides inspection and cleaning; the detailed grid, charts and templates use the smaller-file workspace.
    4. Keep the terminal open while using the app. Use Cancel to stop or discard a large job. Press Ctrl+C in the terminal to stop the server when finished.
    Troubleshooting and privacy

    If the browser does not open, use the address printed in the terminal. If dependencies fail to install, check your connection and Python version; do not use administrator or sudo installation. If the file is rejected, read the message: the 1 GiB limit does not override format, memory-safety or temporary disk limits. Avoid running from a cloud-synced folder for private work. Do not expose the local server through a tunnel or public network address.

    Formula cells and VBA are preserved, never executed by the upload service. Changed inputs can affect calculated results or macro behavior. Do not enable macros from untrusted files. Downloaded reports remain on your device.
