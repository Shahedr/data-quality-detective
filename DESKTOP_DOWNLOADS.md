# Local app: community preview

Download the ZIP for Windows, Mac with Apple Silicon, or Mac with Intel.
Python is included. You do not need to install it or enter commands.

## Windows

1. Download data-quality-detective-windows-x64.zip.
2. In Downloads, right-click the ZIP and select Extract All, then Extract.
3. Open the extracted DataQualityDetective folder. Keep all files together.
4. Double-click DataQualityDetective.exe. A small launcher opens, followed by
   your browser. Keep the launcher open while you work; use Quit to close it.

## Mac

1. Open Apple menu > About This Mac. If it shows Chip and an M-series name,
   choose the Apple Silicon ZIP. If it shows an Intel processor, choose Intel.
2. Download the matching ZIP and double-click it in Downloads to extract it.
3. Drag DataQualityDetective.app to Applications, then open it from Applications.
4. Keep the launcher open while using the browser workspace. Use Quit to close it.

## Publisher-verification warnings

These community builds have no verified publisher signature and are not
notarized by Apple. macOS uses an ad-hoc signature required for execution; it
does not verify the developer's identity. No paid certificate was purchased.

Only download from this repository's official release page. If Windows displays
a publisher/reputation warning, verify the source and published SHA-256 before
deciding whether to proceed. If macOS blocks an unidentified developer, consult
Apple's official guidance: https://support.apple.com/102445. Do not disable
system-wide security protections. If any warning identifies malware, stop and
report it to shahed2338@gmail.com; do not proceed.

Checksums detect changed downloads; they are not a malware-free certification.
Automated packaged-launch, local HTTP, interface-file and sample CSV checks must
pass on all three platforms before these assets are published. Individual devices
and operating-system warning dialogs are not exhaustively tested.

## Working with files

Look for FREE LOCAL WORKSPACE. Expand Large files at the bottom for CSV/XLSX/XLSM
files up to 1 GiB. Inspect first, review changes and download a separate copy.
Charts and the detailed grid use the smaller-file workspace. Original files are
unchanged. Preserved macros remain untrusted unless you know their source.
Cancel active processing before quitting. Keep at least 5 GB of disk space free
for large-file cleaning. Temporary files and downloaded copies stay on your device.

If the browser does not open, select Open workspace in the launcher. The launcher
shows the local address and any startup error. Never expose it to a public network.

The app remains free. To discuss supporting future verified publisher signing and
maintenance, contact shahed2338@gmail.com. No donation is required to use the app.
